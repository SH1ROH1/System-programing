Контрольні запитання :

Високий рівень

1. Поясніть принцип роботи функцій форматного вводу/виводу з пам’яттю та адресацією
змінних.
- printf() читає значення змінних з пам’яті
- scanf()/scanf_s() записують у пам’ять, тому потрібна адреса змінної (&)

2. Як можна керувати шириною поля та точністю виведення чисел у printf()? Наведіть прик-
лад.
-Формат: %ширина.точністьтип:
-   printf("%6.2f", 3.14159); //   3.14

3. Які помилки найчастіше виникають при використанні scanf_s() та як їх уникнути?
- Не вказано розмір буфера для %s
- Ігнорування поверненого значення
- Невідповідність типів

4. Як реалізувати перевірку коректності введених даних при використанні scanf_s()?
- Перевіряти, що scanf_s() повертає 1:
-   if (scanf_s("%d", &x) != 1) { /* помилка */ }

5. Порівняйте використання форматного вводу/виводу з іншими способами введення та ви-
ведення даних у мові C.
- printf/scanf — просто, але небезпечно
- scanf_s — безпечніше
- fgets + sscanf — найнадійніше
